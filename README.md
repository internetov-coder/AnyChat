# AnyChat

Android-приложение (Flutter) для общения с LLM через **ваш API-ключ**:
свой ChatGPT на Material 3 — SSE-стриминг, Markdown-ответы, ветвление
диалога, контроль контекста, вложения (фото / видео / аудио — по
возможностям модели), локализация ru / en / uk.

## Установка

Проект в стадии **alpha**: каждый push с кодом в `main` публикует релиз
`alpha-N` с ассетом `AnyChat-arm64-alpha-N.apk`.

1. Откройте **Releases** → свежий `alpha-N`.
2. Скачайте `AnyChat-arm64-alpha-N.apk` и установите (разрешите установку
   из неизвестных источников).

Требования: Android 7.0+ (minSdk 24), интернет или локальный Ollama.

> Если обновление поверх уже установленной сборки падает с конфликтом
> подписи — установите alpha-1+ один раз «с нуля»; дальше обновления
> встают поверх.

## Быстрый старт

1. **Гамбургер → Настройки → Провайдер → «+»**: название, эндпоинт
   (например `https://api.openai.com/v1`), формат (`openai` у большинства
   шлюзов; `anthropic` / `gemini` — нативные API) и API-ключ. Ключ хранится
   в Keystore, в UI видна только маска `sk-...abcd`.
2. В меню провайдера — **Проверить ключ**: минимальный chat-проба;
   при ошибке показывается её локализованная причина.
3. **Настройки → Модели**: выбор модели (поиск, цена за 1M токенов,
   контекст, бейджи мультимодальности) либо ввод своего ID вручную.
4. Пишите в чат. Drawer: переименование чата, его системный промпт,
   **Сжать историю**, удаление; внизу — «Новый чат» и Настройки.
   Ветвление: правка сообщения создаёт ветку, «Ветка отсюда» — откат.

## Параметры

| Где | Параметр | Что делает |
|-----|----------|------------|
| Генерация | `max_tokens`, таймаут, системный промпт | базовые ограничения запроса; системный промпт есть и глобальный, и по-чатовый |
| Расширенные | `frequency_penalty` (−2…2) | штраф за повторы — только для openai-совместимых |
| Расширенные | `top_k` (1–100) | число кандидатов — только для gemini |
| Расширенные | `reasoning_effort` | уровни приходят **из каталога API** выбранной модели; по умолчанию «Не отправлять» |
| Расширенные | лимит контекста, глубина истории | индикатор контекста и срез последних N сообщений перед отправкой |

Temperature и `top_p` не отправляются вообще — работают дефолты провайдера.

## Вложения

Скрепка в композере включена, только если выбранная модель принимает медиа
(иначе — подсказка «модель не поддерживает вложения»):

| Медиа  | Форматы файлов            | Лимит |
|--------|---------------------------|-------|
| Фото   | jpg, jpeg, png, webp, gif | 20 МБ |
| Видео  | mp4, mov, webm            | 20 МБ |
| Аудио  | mp3, wav                  | 20 МБ |

Отправляются по формату провайдера: openai → `image_url` / `input_audio` /
`video_url`, anthropic → `image` (base64), gemini → `inlineData`.
Возможности модели определяются по каталогу провайдера и по её ID; если
данных нет — модель считается текстовой.

## Ограничения (alpha)

- Только Android; нет iOS / web / desktop.
- Нет подсветки синтаксиса кода — код-блоки моноширинные, без цветов.
- Нет tool calling и генерации изображений; вложения — только готовые
  файлы (без записи с микрофона), `video_url` — best-effort.
- Нет экспорта чатов и поиска по истории; лог ошибок живёт в памяти.
- Индикатор контекста — эвристика без токенизатора (значение
  «приблизительно», когда лимит модели неизвестен).
- `reasoning_effort` работает только с openai-совместимыми API и только
  когда включён вручную; thinking-токены видны, если провайдер их
  присылает.
- Fork ветки копирует сообщения — на очень длинных историях это заметная
  задержка.
